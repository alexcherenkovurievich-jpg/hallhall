# BrandPrime — лендинг

Одностраничный сайт веб-студии. Чистый HTML + CSS + ванильный JavaScript,
без фреймворков, сборки и внешних библиотек.

```
index.html        вся разметка и весь текст сайта
css/styles.css    стили, 18 пронумерованных секций
js/main.js        анимации, 8 пронумерованных секций
```

## Как задеплоить на Netlify

**Способ 1 — перетаскиванием (30 секунд, без Git)**

1. Откройте https://app.netlify.com/drop
2. Перетащите туда папку с проектом целиком (не архив).
3. Сайт сразу поднимется на адресе вида `random-name-123.netlify.app`.

**Способ 2 — из репозитория (обновляется сам при каждом пуше)**

1. В Netlify: *Add new site → Import an existing project → GitHub*.
2. Выберите этот репозиторий.
3. Build command оставьте **пустым**, publish directory — `.` (точка).
   Сборка не нужна: файлы отдаются как есть.
4. *Deploy site*.

**Свой домен:** *Site configuration → Domain management → Add a domain*,
дальше Netlify покажет, какие DNS-записи прописать у регистратора.
HTTPS-сертификат выпускается автоматически.

## Как приходят заявки

Формы на сайте нет — все кнопки «Обсудить проект» ведут в секцию
«Контакты», где стоят две кнопки: **Написать в Telegram** и
**Позвонить**. Заявки приходят напрямую в мессенджер и на телефон,
никакого бэкенда и панели с сообщениями не нужно.

## Где менять тексты и контакты

Весь текст лежит в `index.html` — правится прямо там, разметка разбита
комментариями по секциям (`ШАПКА`, `ПЕРВЫЙ ЭКРАН`, `ПАКЕТЫ` и т.д.).

Что чаще всего нужно поменять:

| Что | Где искать в `index.html` |
|---|---|
| Телефон | `href="tel:+79176358265"` — два места: блок контактов и футер |
| Telegram | `https://t.me/Alexcherenkovv` — два места: контакты и футер |
| Названия и цены пакетов | секция `ПАКЕТЫ`, классы `package__name` и `package__price` |
| Пункты в карточках | списки `package__list` |
| Этапы работы | секция `ЭТАПЫ РАБОТЫ` |
| Заголовок вкладки и описание для поиска | теги `<title>` и `<meta name="description">` в самом верху |

**Цены:** менять только текст внутри `<span class="count">`. Скрипт сам
берёт из него итоговое число и анимирует счётчик — отдельно в JS ничего
править не нужно.

**Курсивные акцентные слова** (золотые, с подчёркиванием) размечены как
`<em class="accent-word">слово</em>`. Правило простое: не больше одного
такого слова на блок, иначе приём перестаёт работать.

## Где менять оформление

Все цвета, шрифты, ширина контейнера и вертикальный ритм собраны в одном
месте — блок `:root` в начале `css/styles.css`. Под другого клиента
перекрашивается правкой этих переменных, трогать остальной файл не нужно.

```css
--bg          фон страницы
--bg-dark     фон тёмных секций
--text        основной текст
--text-muted  вторичный текст
--gold        акцент: линии, иконки, рамки, цифры
--gold-deep   акцент в тексте и наведение на кнопки
--section-gap расстояние между блоками
```

Шрифты подключаются одной строкой `<link>` в `<head>` — при замене
не забудьте поправить и переменные `--font-head` / `--font-body` /
`--font-accent`.

## Что учтено

- Mobile-first, проверено на 390px и 1440px — горизонтальной прокрутки нет.
- Контраст текста проходит WCAG AA.
- При отключённом JavaScript страница полностью читается: анимации
  спрятаны за классом `.js`, который ставится до первой отрисовки.
- При системной настройке «уменьшить движение» анимации выключаются.
