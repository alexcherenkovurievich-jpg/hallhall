# Юго-Запад Hall

Одностраничный сайт закрытой площадки отдыха в Ульяновске.
React + Vite + Tailwind, анимации на Framer Motion, инерционный скролл — Lenis.

```
index.html              точка входа Vite
src/App.jsx             сборка страницы из секций
src/components/         секции и общие компоненты
src/lib/content.js      ВСЕ ТЕКСТЫ И КОНТАКТЫ — правятся здесь
src/lib/motion.js       длительности и easing анимаций, одни на весь сайт
src/index.css           стили: токены, компоненты, анимации
public/images/photos/   фотографии
public/fonts/           Fraunces и Manrope, самохостом
scripts/build-preview.mjs  однофайловая версия для показа (на боевой сайт не влияет)
prototype/              статичный макет, с которого всё начиналось
legacy/brandprime/      прежний сайт из этого репозитория, не используется
```

## Запуск

```bash
npm install
npm run dev       # разработка, http://localhost:5173
npm run build     # сборка в dist/
npm run preview   # посмотреть собранное
```

## Деплой на Netlify

`netlify.toml` уже настроен: команда `npm run build`, публикуется `dist`.
В Netlify: *Add new site → Import an existing project*, выбрать репозиторий,
остальное подхватится из конфига.

## Где что менять

| Что | Где |
|---|---|
| Тексты, телефоны, ссылки на Telegram и ВК | `src/lib/content.js` |
| Пункты меню | `NAV` в `src/lib/content.js` |
| Ключ и координаты карты | начало `src/components/Location.jsx` |
| Цвета, шрифты, шкала размеров | `tailwind.config.js` и `:root` в `src/index.css` |
| Скорость и характер анимаций | `src/lib/motion.js` |
| Фотографии | `public/images/photos/`, подключены в `content.js` и секциях |

## Анимации

Единый почерк: `opacity 0→1` + `translateY(40px→0)`, 1.1 с,
easing `cubic-bezier(0.16, 1, 0.3, 1)`, задержка 0.15 с, каскад 0.11 с.
Заголовки выезжают из-под маски, первый экран — медленный зум фона плюс
параллакс, лента отзывов крутится сама и тормозится наведением.
При системной настройке «уменьшить движение» остаётся только мягкий fade.

## Карта

Yandex Maps JavaScript API. Ключ, координаты и зум — константами в начале
`src/components/Location.jsx`. Зум колёсиком отключён, чтобы страница
прокручивалась над картой; кнопки зума на месте, метка неперетаскиваемая.
Если API не ответил, вместо карты показывается адрес и ссылка на Яндекс.Карты.
