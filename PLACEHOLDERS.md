## Как менять фотографии

Файл кладём в `public/images/photos/`, дальше правим `src/lib/content.js`:
там перечислены все кадры с путями, размерами и alt-текстами.
`pos` сдвигает кадрирование, когда пропорция фото не совпадает с рамкой
(`center 70%` тянет видимую область к низу). Вертикальный кадр в широком
блоке ставится по центру классом `ph--tall`.

Первый экран прописан прямо в `src/components/Hero.jsx`.

## Просмотр в большом размере

По клику любой кадр открывается поверх страницы. Список для листания
собирается из всех кадров на странице в порядке сверху вниз — ничего
регистрировать вручную не нужно, новое фото попадает в него само.
Закрытие: крестик, клик по фону, Esc. Листание: стрелки на экране
и клавиши влево-вправо.

Первый экран из лайтбокса исключён намеренно: он во весь экран, и клик
по нему конфликтовал бы с кнопкой «Связаться с нами».

## Вес страницы

Фотографии лежат как есть, без обработки — так и просили. Сейчас это
41,7 МБ на всю страницу. Для сайта, который открывают с телефона, много:
уменьшение до 1600 px по длинной стороне и WebP снимет примерно 90%
веса без заметной разницы на глаз. Скрипт `scripts/preview-images.py`
делает такие копии, но только для однофайлового предпросмотра —
на сайт они не идут.

## Порядок секций

Карта («Расположение») стоит перед «Контактами» — сразу после «Отзывов».

## Карта

Yandex Maps JavaScript API. Ключ, координаты и зум — константами
в начале `src/components/Location.jsx`. Зум колёсиком отключён,
кнопки зума оставлены, метка неперетаскиваемая. Если API не ответил,
вместо карты показывается адрес и ссылка на Яндекс.Карты.
