## Как подставлять

Файл кладём в `public/images/photos/`, дальше — в зависимости от блока.

Территория и услуги описаны данными: в `src/lib/content.js` у зоны или
карточки вместо `tone`/`label` указываем `photo`:

```js
photo: { src: '/images/photos/файл.jpg', w: 1500, h: 1125,
         pos: 'center 70%', alt: 'что на кадре' },
```

Галерея, отзывы и контакты — там же в `content.js`, у элемента появляются
`src` и `alt` вместо `tone` и `label`. Лайтбокс включится сам: он
показывает только кадры, у которых есть `src`.

`pos` сдвигает кадрирование, когда пропорция фото не совпадает с рамкой
(`center 70%` тянет видимую область к низу). Вертикальный кадр в широком
блоке лучше не растягивать — для этого есть класс `ph--tall`, он ставит
фото по центру и ограничивает ширину.

## Разрешение

Все присланные кадры проходят через сжатие мессенджера. Если есть
оригиналы с телефона — их лучше положить вместо текущих: первый экран
растягивает фото на всю ширину экрана, и там запас по разрешению виден.

## Порядок секций

Карта («Расположение») стоит перед «Контактами» — сразу после «Отзывов».

## Карта

Яндекс.Карта через Yandex Maps JavaScript API. Ключ, координаты и зум —
константами в начале `src/components/Location.jsx`:

```js
const YANDEX_MAPS_API_KEY = '...';
const VENUE_COORDS = [54.272215, 48.248568];   // [широта, долгота]
const VENUE_ZOOM   = 16;
```

Зум колёсиком отключён, кнопки зума оставлены, метка неперетаскиваемая.
Если API не загрузился, вместо карты показывается адрес и ссылка
на Яндекс.Карты. Под картой — кнопка «Открыть в Яндекс.Картах»
(в её ссылке порядок координат обратный: долгота, широта).
