# Прототип «Юго-Запад Hall» — Этап 1

Статичный визуальный макет лендинга. **Это только картинка-прототип**, не рабочий сайт:
никакого React, Vite, Lenis, Framer Motion и GSAP здесь нет — они появятся на Этапе 2,
после утверждения макета.

```
proto.html        макет целиком (HTML + CSS, один файл)
fonts/            Fraunces + Manrope, скачаны локально (рендер без интернета)
preview/          готовые скриншоты — desktop.jpg и mobile.jpg
shot.mjs          скрипт съёмки скриншотов (Playwright + Chromium)
```

## Посмотреть

Открыть `proto.html` в браузере. Или пересобрать скриншоты:

```bash
npm i playwright
node shot.mjs      # положит PNG в out/
```

Полностраничная съёмка идёт при DPR 1 намеренно: страница высокая, и при DPR 2
она выходит за лимит Chromium в 16384 px — в скриншоте появляются пустые белые полосы.
Детальные кадры секций снимаются при DPR 2, там высота небольшая.

## Дизайн-токены

Взяты из брифа один в один. Палитра, шкала типографики и вертикальные отступы
заданы CSS-переменными в начале `proto.html` — на Этапе 2 они переезжают
в `tailwind.config.js` как есть.
